# Флаг перегрева «плечо (OI)» — убран (09.10.2026)

**Решение:** `oi_rel365` (открытый интерес Bybit BTCUSDT **в монетах BTC** / среднее за 365 дн.
≥ 1.3) исключён из `market_regime.hot_flags`. Перегрев теперь — 7 флагов. Колонка `oi_btc`
собирается дальше, `run.py market` показывает OI справочно.

**Почему.** В монетах OI растёт, когда цена BTC падает (тот же долларовый OI — больше монет).
Флаг горел 100% дней 2022, на дне (alt_dd ≥ 0.65, 211 дн.) — 100% дней, из них в 73% —
единственным. Исполнитель (`executor.hot_block`, ≥ 1 флаг) не купил бы на дне ни разу, а
множитель ×0.75 резал все пружины дна.

## Три варианта (прод-функции, in-sample, 2 цикла)

V0 — 8 флагов как было; V1 — без OI; V2 — OI **в USD** (oi_btc × open BTCUSDT дня) к среднему
за 365 дн., тот же порог. Флаг OI есть в данных только с 2021-05-31.

| | V0 | V1 (принят) | V2 |
|---|---|---|---|
| ≥ 1 флага, 2020/21/22/23/24/25 | 46/100/100/12/65/58% | 46/99/42/7/65/58% | 46/100/53/**60**/81/58% |
| Дно 2022: исполнитель заблокирован | **100%** | **26%** | 40% |
| Вершины 2021-01…11: ≥1 / ≥3 флагов | 100% / 91% | 99% / 66% | 100% / 92% |
| Дни выхода (≥ 3 флагов), 2021 | 307 | 222 | 314 |
| R 2023-26, холод vs ≥ 1: медиана / win | +10.0 / 58% vs −18.5 / 34% | +10.0 / 59% vs −21.1 / 25% | +10.0 / 71% vs −17.5 / 38% |
| Холод − тепло внутри одного года (R, медиана) | +10.3 пп (4 года) | +15.3 пп (5 лет) | +18.3 пп (5 лет) |
| Фильтр «холодный рынок»: срезано лучших исходов R / H | 31% / 33% | **19% / 15%** | 62% / 50% |
| Портфель «как исполнитель» R: n, P&L (альты / BTC) | 227, +$982 (+1740 / +1465) | 284, +$933 (+1775 / +1376) | 227, +$1083 (+1663 / +1206) |
| Портфель «как исполнитель» H: n, P&L (альты / BTC) | 138, +$3875 (+2683 / +2131) | 181, +$4013 (+2751 / +2145) | 157, +$3240 (+2612 / +1919) |

- **Сплит V0 в 2020-22 был календарным:** в «холодной» корзине нет ни одного эпизода 2021–22 —
  весь холод в 2020, отсюда «P(+100) 100%». У V1 корзины перемешаны внутри года (2022: холод
  470 эпизодов R медиана −1.4% против −21.1% у 315 тёплых), разрыв сохраняется.
- **Что горит у V1 в 2022:** mvrv_eth (январь–май, хвост вершины) и altbtc_chg90 (август–октябрь,
  отскок вокруг слияния ETH) — исторически плохие дни для входа.
- **Цена:** V1 теряет часть дней «≥ 3 флагов» в июне–октябре 2021 (раннее предупреждение
  перед вершиной в октябре); ноябрь 2021 (вершина) — 30/30 дней у обоих. Выход по перегреву —
  только информационный алерт (`market_hot`), продаж не делает.
- **V2 не брать:** OI в USD = рост самой Bybit + импульс цены; горит весь подъём 2023
  (53% дней 2023 — единственным), фильтр срезает 62% лучших исходов R, на выходе хуже всех.
  Замена на OI альтов (USD или к капе) проверена раньше — тоже нет
  ([ALT_LEVERAGE_REPORT](ALT_LEVERAGE_REPORT.md)).
- Портфельные различия V0/V1 — в пределах шума (знак меняется между R и H). Пороги всех
  флагов подобраны на тех же вершинах — без обещаний доходности.

## Как воспроизвести

`backtest/oi_flag/`: сделать три копии кода `code_v0|v1|v2` рядом со скриптами (данные —
`scanner.db` и `.cache/` основного каталога), в `code_v0/config.json` вернуть
`"oi_rel365": [">=", 1.3, 1.15]` в `hot_flags`, к `code_v2` применить `v2_oi_usd.patch` (и тот
же ключ в config). Затем `run_backtests.sh v0|v1|v2` (market_regime_study, junk_filter_study,
portfolio_vs_market, hot_exit_study), `measure_flags.py`, `entry_split.py`, `compare.py`.
Результаты V1 — в `backtest/*_results.json`, сводки — `flags_results.json`,
`entry_split_results.json`.
